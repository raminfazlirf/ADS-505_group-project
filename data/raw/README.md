# Raw Data

Source: Cukierski, W., & Knauer, F. (2015). *Rossmann Store Sales* [Data set]. Kaggle. https://www.kaggle.com/competitions/rossmann-store-sales

Files:
- `train.csv`: 1,017,209 daily sales records for 1,115 stores
- `store.csv`: static attributes for the 1,115 stores

`test.csv` (Kaggle competition holdout, no Sales column) was not needed for this project's statistical analysis and is not included.
